# How to use (for AI assistants)

1. Get `sticker_kit.py`: it is uploaded, or download
   https://raw.githubusercontent.com/filep48/sticker-kit/main/sticker_kit.py
2. Run `python sticker_kit.py selftest`. If it fails, report it and stop.
3. Run `python sticker_kit.py guide` and follow it.

Cut the original pixels. Never generate or redraw images.
